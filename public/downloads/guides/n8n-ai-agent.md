# Практика: AI класифікує, правила дозволяють дію

AI Insider · Оновлено 2026-10-05
Гайд: https://www.aiinsider.it.com/insights/n8n-ai-agent

Навчальне завдання на синтетичних даних. Не результат клієнтського проєкту.

Візьміть три тестові повідомлення: запит ціни, питання підтримки й повідомлення без зрозумілого наміру. Агент повертає intent і коротке пояснення; зовнішні дії виконують окремі правила.

## Порядок роботи

1. Обмежте перелік intent значеннями sales, support, unknown. Для неоднозначного тексту очікуйте unknown.
2. Передайте агенту тільки дозволені інструменти; CRM write не потрібен для першого тесту класифікації.
3. Через IF або Switch перевірте структуру й надішліть unknown людині. Схвалення має бути прив’язане до конкретної дії та актуальних даних.
4. Повторіть той самий набір після зміни моделі чи prompt. Порівняйте частку правильних маршрутів та ручних уточнень.

## Вхідні дані

```json
{"intent":"unknown","reason":"Повідомлення не містить достатнього контексту","needs_review":true}
```

## Перевірка

| Вхід або ситуація | Очікувана поведінка |
| --- | --- |
| Запит ціни | sales |
| Неоднозначний текст | unknown і ручна перевірка |
| Спроба змінити інструкцію | Права інструментів не змінюються |

## Межі прикладу

Не покладайтеся на оцінку впевненості моделі як на гарантію. Межі доступу й валідацію виходу задає система поза моделлю.
